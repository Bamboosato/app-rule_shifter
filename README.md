## 🌟 概要 (Overview)

**Rule Shifter（ルール・シフター）** は、臨床神経心理学における前頭葉機能評価の金字塔「**ウィスコンシン・カード分類課題（Wisconsin Card Sorting Test: WCST）**」を一筆書き迷路に完全統合した脳トレ・Webパズルゲームです。

プレイヤーは「色・形・数・模様」の4次元属性を持つ幾何学トークンが並ぶ迷宮を探索しますが、**「どの属性が合法な接続キーになっているか」は一切明かされません**。
隣接マスを踏んだ瞬間のバイナリフィードバック（Pass / Reject）のみから隠された法則を帰納推理し、さらに途中で突如発生する「ルールのサイレント急変（相転移）」に適応して過去の成功体験を即座に破棄しながらゴールを目指します。

## 🎮 主な機能・特徴 (Features)

### 1. ブラックボックス接続 ＆ アブダクション（仮説形成）
* 画面にルール説明はありません。「形が同じマスなら進めるのか？」「色が一致しているのか？」を最小限の試行から推理します。

### 2. サイレント相転移（Silent Phase Shift）
* 渦巻きマス（🌀）を踏破すると、有効ルールが予告なく別の属性次元（または複数属性の同時一致）へと急変します。

### 3. ライフ制（❤️ 3）＆ 保続エラー検出
* 3回のミスでゲームオーバーとなるライフ制を採用（『Stroop Route』共通UI）。
* 相転移の直後に「直前まで正しかった旧ルール」に執着して誤タップした回数（保続エラー）を厳密に追跡し、画面上に警告トーストが表示されます。

### 4. 全ステージ「唯一解（Unique Solution）」＆ 長い直線の完全排除
* 全てのステージで裏道やショートカットを完全遮断し、**正解ルートが厳密に1つだけ**になるよう自動検証されています。
* 連続直線は最大3セル（直進2歩）以内に制限され、迷宮らしいジグザグの探索性を徹底しています。

### 5. 正解属性ガイド（設定アシスト機能）
* 設定（⚙）から「正解属性ガイド」をONにすると、現在の正解属性（色 🎨 / 形 🔷 / 数 🔢 / 模様 ▦）にエメラルドの「●」がリアルタイム点灯（相転移時も連動）。初期状態はOFFで、設定はブラウザに永続保存されます。

### 6. 『Stroop Route』完全準拠の洗練されたUI/UX
* **完全3段ヘッダー**: 1段目（タイトル・ステージ選択・設定）、2段目（タイマー・手数・ライフ・リセット）、3段目（ステージ特徴バナー）。
* **経路直接タップ巻き戻し**: 通過済みのマスをタップするだけで、その地点まで一括で安全に巻き戻せます。
* **巨大等幅タイポグラフィ**: タイマー・手数・残りライフを `tabular-nums` で大きく鮮明に表示。
* **CSS Container Queries（`100cqw`）**: 全ステージでマス目の大きさが均一に整う設計。

### 7. プロシージャルシンセサウンド（Web Audio API）
* 外部音声ファイルゼロ。ブラウザ内部でペンタトニックPass和音、下降Sawtooth Reject音、相転移シマー音をリアルタイム合成。

## 🕹 操作方法 (Controls)

| 操作対象 | スマホ・タッチ | PCマウス | PCキーボード |
| :--- | :--- | :--- | :--- |
| **ルートを伸ばす** | 先端マスから指でなぞる / タップ | 先端からドラッグ / マスクリック | 矢印キー（`↑` `↓` `←` `→`） / `W` `A` `S` `D` |
| **迷宮をスライド（5x5〜10x10）** | 盤面スワイプ / ミニドットタップ | 盤面ドラッグ / ミニドットクリック | 矢印キー（ファインダー端到達時自動追従） |
| **経路を巻き戻す（Rewind）** | 通過済みルートのマスを直接タップ | 通過済みマスを直接クリック | 逆方向へ移動 |
| **ステージリセット** | 右上「リセット」ボタン | 「リセット」ボタン | `R` キー |
| **ステージ詳細確認** | 3段目バナー（潜伏規則推理）をタップ | バナーをクリック | — |
| **正解属性ガイド切替** | 右上 ⚙（設定）➔「正解属性ガイド」 | ⚙（設定）➔「正解属性ガイド」 | — |

## 🧩 ステージ構成 (Stages)

| ステージ | タイトル | 盤面サイズ | 表示形式 | 有効潜伏ルール推移 | 特殊ギミック |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Stage 1** | 入門 (単一規則推理) | 4×4 | 全体固定表示 | `色一致` (固定) | 相転移なし（基本学習） |
| **Stage 2** | 初級 (形状へのシフト) | 4×4 | 全体固定表示 | `色一致` ➔ `形状一致` | シフターノード × 1箇所 |
| **Stage 3** | 中級 (個数と模様の交差) | 5×5 | 4×4ファインダー (2×2) | `個数一致` ➔ `模様一致` | スワイプ視界、シフターノード × 1 |
| **Stage 4** | 広大迷宮 (形状から色彩へ) | 7×7 | 4×4ファインダー (2×2) | `形状一致` ➔ `色一致` | 4区画スワイプ、シフターノード × 1 |
| **Stage 5** | 超巨大メガ迷宮 (2段変異) | 10×10 | 4×4ファインダー (3×3) | `色一致` ➔ `個数一致` ➔ `形状一致` | 9区画スワイプ、シフターノード × 2 |
| **Stage 6** | 複合転移 (色と形の共鳴) | 7×7 | 4×4ファインダー (2×2) | `色一致` ➔ `色 AND 形状一致` | 複合属性同時一致、シフター × 1 |
| **Stage 7** | 高密度複合迷宮 (幾何学交差) | 7×7 | 4×4ファインダー (2×2) | `形状` ➔ `形状＆模様` ➔ `個数＆模様` | 複合2段階相転移、シフター × 2 |
| **Stage 8** | グランドマスター (複合三段変異) | 9×9 | 4×4ファインダー (3×3) | `色＆形` ➔ `形＆模様` ➔ `色＆数` ➔ `数＆模様` | 最難関3段階相転移、シフター × 3 |
| **Daily** | デイリーチャレンジ | 7×7 | 4×4ファインダー | 日替わり自動生成 | 全世界共通の日替わりシード盤面（唯一解保証） |

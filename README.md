## 🌟 概要 (Overview)

**Rule Shifter（ルール・シフター）** は、臨床神経心理学における前頭葉機能評価の金字塔「**ウィスコンシン・カード分類課題（Wisconsin Card Sorting Test: WCST）**」を一筆書き迷路に完全統合した脳トレ・Webパズルゲームです。

プレイヤーは「色・形・数・模様」の4次元属性を持つ幾何学トークンが並ぶ迷宮を探索しますが、**「どの属性が合法な接続キーになっているか」は一切明かされません**。
隣接マスを踏んだ瞬間のバイナリフィードバック（Pass / Reject）のみから隠された法則を帰納推理し、さらに途中で突如発生する「ルールのサイレント急変（相転移）」に適応して過去の成功体験を即座に破棄しながらゴールを目指します。

## 🎮 主な機能・特徴 (Features)

### 1. ブラックボックス接続 ＆ アブダクション（仮説形成）
* 画面にルール説明はありません。「形が同じマスなら進めるのか？」「数が一致しているのか？」を最小限の試行から推理します。

### 2. サイレント相転移（Silent Phase Shift）
* 渦巻きマス（🌀）を踏破、または歩数経過により、有効ルールが予告なく別の属性次元へ急変します。

### 3. 保続エラー（Perseverative Error）検出 ＆ 瞬間トースト
* 相転移の直後に「直前まで正しかった旧ルール」に執着して誤タップした回数を厳密に追跡。画面上部に「⚠️ 旧ルールへの固執！（保続エラー）」が警告表示されます。

### 4. 認知的柔軟性スコア（Flexibility Index / 100点満点）
* クリア時に「セットシフティング（思考切替速度）」「保続抑制（脱・成功体験）」「最短手数」を総合評価し、Wordle風テキストでSNSに共有可能。

### 5. 『Stroop Route』完全準拠のUI/UX ＆ 視認性
* **CSS Container Queries（`100cqw`）**: 4×4、5×5、7×7、10×10の全ステージで、画面に見えるマスの大きさ（横幅の約1/4）が完全均一。
* **巨大等幅タイポグラフィ**: タイマー・手数・保続エラー数を `tabular-nums` で大きく鮮明に表示。
* **仮説メモトグル（Hypothesis Scratchpad）**: 画面直下に色・形・数・模様の4ボタンを常設し、未定(?)・有力(✓)・棄却(×)を外在化可能。

### 6. プロシージャルシンセサウンド（Web Audio API）
* 外部音声ファイルゼロ。ブラウザ内部でペンタトニックPass和音、下降Sawtooth Reject音、相転移シマー音をリアルタイム合成。

## 🕹 操作方法 (Controls)

| 操作対象 | スマホ・タッチ | PCマウス | PCキーボード |
| :--- | :--- | :--- | :--- |
| **ルートを伸ばす** | 先端マスから指でなぞる / タップ | 先端からドラッグ / マスクリック | 矢印キー（`↑` `↓` `←` `→`） / `W` `A` `S` `D` |
| **迷宮をスライド（5x5, 7x7, 10x10）** | 盤面スワイプ / ミニドットタップ | 盤面ドラッグ / ミニドットクリック | 矢印キー（ファインダー端到達時自動追従） |
| **1手戻す（Undo）** | 1つ手前のマスをタップ / 「戻す」ボタン | 1つ手前をクリック | `Z` キー / `BackSpace` |
| **ステージリセット** | 「リセット」ボタン | 「リセット」ボタン | `R` キー |
| **仮説メモ切替** | メモボタンタップ (色・形・数・模様) | メモボタンクリック | `1` `2` `3` `4` キー |

## 🧩 ステージ構成 (Stages)

| ステージ | タイトル | 盤面サイズ | 表示形式 | 有効潜伏ルール推移 | 特殊ギミック |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Stage 1** | 入門 (単一規則推理) | 4×4 | 全体固定表示 | `色一致` (固定) | 相転移なし（基本学習） |
| **Stage 2** | 初級 (形状へのシフト) | 4×4 | 全体固定表示 | `色一致` ➔ `形状一致` | シフターノード × 1箇所 |
| **Stage 3** | 中級 (個数と模様の交差) | 5×5 | 4×4ファインダー (2×2) | `個数一致` ➔ `模様一致` | スワイプ視界、シフターノード × 1 |
| **Stage 4** | 広大迷宮 (サイレント転移)| 7×7 | 4×4ファインダー (2×2) | `形状一致` ➔ `色一致` | 4区画スワイプ、サイレント相転移 |
| **Stage 5** | 超巨大メガ迷宮 (2段変異) | 10×10 | 4×4ファインダー (3×3) | `色一致` ➔ `個数一致` ➔ `形状一致` | 9区画スワイプ、シフターノード × 2 |
| **Daily** | デイリーチャレンジ | 7×7 | 4×4ファインダー | 日替わり自動生成 | 全世界共通の日替わりシード盤面 |
